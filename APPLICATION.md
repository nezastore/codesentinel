## What We're Building

CodeSentinel is an autonomous code review agent powered by Claude AI.

Every year, **$3.1 trillion** is lost to software bugs globally. Manual code reviews are slow, inconsistent, and often miss critical issues. We're solving this by building an AI agent that reviews every pull request automatically — catching bugs, security vulnerabilities, and performance issues before they reach production.

---

## How We Use Claude

**Current Setup**: We access Claude via OpenRouter using `claude-3-5-sonnet`.

**Integration**:
- Code analysis using Claude's superior code understanding
- Structured JSON output for consistent issue reporting
- Multi-language support for analyzing 95+ programming languages

**Why Claude**:
- Best-in-class code reasoning
- Reliable structured output generation
- 200K token context for large file analysis
- Cost-effective via OpenRouter
