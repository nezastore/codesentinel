# CodeSentinel - Autonomous Code Review Agent

**AI-powered code review that thinks, suggests, and fixes.**

## Problem
Code reviews are slow, inconsistent, and often miss critical bugs. Manual reviews take hours, miss edge cases, and vary wildly between reviewers.

## Solution
CodeSentinel is an autonomous code review agent that:
- Analyzes pull requests automatically
- Identifies bugs, security vulnerabilities, and performance issues
- Suggests concrete fixes with code patches
- Learns from your codebase patterns

## Tech Stack
- **Backend**: Node.js + Python (Claude API integration)
- **AI**: Claude via Databyte/OpenRouter
- **Integration**: GitHub API, GitLab API, Webhook support
- **Dashboard**: React + Tailwind

## Features
- [ ] PR auto-analysis on open/updated
- [ ] Security vulnerability scanning (OWASP Top 10)
- [ ] Performance bottleneck detection
- [ ] Auto-generate fix PRs
